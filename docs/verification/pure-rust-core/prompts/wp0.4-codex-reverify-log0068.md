Không tạo worktree, reset/stash/clean, commit/push, bump version, tự sửa implementation, mở WP0.5 hay đóng G0.

Đọc AGENTS.md **hiện hành** (gồm quy tắc reuse/dependency/root-cause mới), guidelines.md, CONSTRAINTS.md, start-here, STATUS/WORKLOG, detailed plan WP0.4, efficient-execution protocol, ADR 0001, toàn bộ report, `artifacts/wp0.4/independent-review-log0068-codex-20260927/review-findings.md` và prompt remediation cùng vòng. Rà lại các đường production và thử bác bỏ bốn lỗi bằng probe thực tế:

1. Nhánh Rust embedded nhận rõ guard/generation từ `InstanceCoordinator` của Tauri, còn process caller kế thừa đúng hợp đồng được truyền; từ chối partial/invalid, không có hai owner cùng generation. Updater exclusive lock không thành công trong khi executor sống. Dùng caller Rust production và seam Tauri thực tế chứ không chỉ spawn native binary bằng fixture env.
2. Drop, protocol error, crash, parent EOF và cancellation giữ guard qua native accepted/active drain, đóng admission, cleanup trước replacement; thử active descendant và lỗi/stall. Không coi `child.kill()/wait()` là bằng chứng native drain.
3. Rust và Node tạo guard Mac đúng 0600 trên umask thông thường, không hạ tiêu chuẩn validator. Chạy live macOS aarch64 executor, Seatbelt, guardian, cancellation, updater và packaged runtime trên exact source/binary. Nếu Mac không kết nối, ghi `NOT_RUN` và không DONE khi tiêu chí platform chưa đủ.
4. Node standalone lẫn inherited Mac guard dùng state thực sự truyền cho child để quyết định timeout/error/restart; kiểm tra Node rollback tới staged packaged candidate không cần `JUDGEDESK_EXECUTOR_PATH` override.

Re-test LOG-0067 malformed JSON và unknown type riêng từng framed request sau health preflight: error, EOF, nonzero exit, no later health, ready replacement only after old exit. Trace all WP0.4 criteria (a)–(j), F5 runtime unwrap/expect tách test-only và poisoned mutex, packaged `--test-*` host dispatch tách khỏi sandboxed payload. Đối chiếu exact staged hash/size, target-triple release output, recipe, provenance và old unselected target/release. Không suy diễn token env là authentication.
