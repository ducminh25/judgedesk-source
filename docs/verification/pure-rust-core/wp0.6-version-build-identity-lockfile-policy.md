`scripts/build-metadata.js` holds the existing Node legacy resolver (re-export preserved from build-server-lib.js) and strict identity policy. Direct Cargo uses the already-required pinned Node runtime, checks .nvmrc, and generates typed Rust constants without build dependencies. Packaged Cargo also runs the unchanged eight-file version checker. No request-time metadata fallback exists. Development Rust ignores injected release labels and marks builtAt development/buildNumber local; legacy unbundled Node behavior remains compatible. This deliberately does not claim a dev build is a reproducible release.

Packaging uses prepare-build-environment.js to derive actual local checkout provenance or validate explicit Git-less archive provenance; its CLI emits only named nonsecret metadata keys. All local npm package entry points run build-packaged.js; the Windows variant builder saves/restores its injected environment. CodeMagic records app/commit/state/number/epoch and enables packaged mode at the sidecar/package boundary after source tests. Tauri release-profile builds reject absent packaged mode, including direct invocation. Its build.rs validates the same build environment; core dependency builds derive core target/features independently. Existing Rust launches append that core identity to backend.log through one shared helper. Node startup logs the esbuild-injected metadata.
