test một nhánh cũ không thay thế bằng chứng release.

## Nội dung release

### Hiệu năng

- Native executor ghi telemetry theo pha để phân biệt spawn, cache ACL,
  self-test và thời gian backend sẵn sàng mà không đổi policy bảo mật.
- Windows bỏ qua việc áp ACL đệ quy khi descriptor hiện tại khớp chính xác; mọi
  mismatch/inspection failure vẫn đi qua đường sửa hoặc fail-closed cũ.
- Phiên chấm lập chỉ mục source/test và metadata cấu hình điểm/time limit đúng
  một lần; không tính trước điểm kết quả trước khi chạy bài/checker.
- Scoreboard lập chỉ mục kết quả, memo hóa row và coalesce progress theo frame.
- Archive `.judgedesk`, Excel worker, toolchain package inspection và polling
  được tách khỏi hot path hoặc chống chạy chồng lặp.

### Xuất Excel

- Cho phép xuất khi có ít nhất một thí sinh hoặc một bài; dữ liệu chưa chấm để
  trống, không biến thành 0 hoặc “Không có bài”.
- Windows có Microsoft Excel dùng `/t` với nguồn `Book.xlsx` để tạo workbook mới
  chưa lưu. Fallback Windows/macOS chỉ giao cùng file `.xlsx` cho hệ điều hành.
- Không tạo/hiển thị `.xltx`, `.csv` hay `.ods`; payload có giới hạn tổng 256 MiB.
- GUI gate thủ công phải xác nhận `Ctrl+S` và đóng workbook hiện Save As trên
  máy Windows có Excel. macOS không được mô tả là có Book1 semantics nếu chưa
  có automation riêng được test trên Apple Silicon.

### Build và dependency

- Node.js `24.19.0`, npm `11.17.0`, Rust `1.97.1` và Tauri v2 theo lockfile.
- GitHub Actions tiếp tục pin exact commit SHA.
- Không đổi language/toolchain scope: C++, C, Python, Pascal và Java.
- v1.3.3 tái sử dụng public `toolchains-v2` bất biến nếu catalog/blueprint/scope
  so với manifest đã công bố không đổi; chỉ xác minh lại, không republish key hay
  package giống hệt dưới cùng tag.

## Public asset allowlist

Release public phải có đúng bảy asset sau; `.sig` chỉ tồn tại trong staging và
chữ ký của Full updater được nhúng vào `latest.json`.

```text
JudgeDesk_1.3.3_core_x64_en-US.msi
JudgeDesk_1.3.3_full_x64_en-US.msi
JudgeDesk_1.3.3_core_aarch64.dmg
JudgeDesk_1.3.3_full_aarch64.dmg
JudgeDesk_1.3.3_full_aarch64.app.tar.gz
SHA256SUMS
latest.json
```

`latest.json` chỉ được chọn Full MSI cho `windows-x86_64` và Full app archive
cho `darwin-aarch64`. Core là lựa chọn tải thủ công.

## Signing limitations phải ghi trong release notes

- Windows MSI chỉ được gọi là Authenticode-signed nếu kiểm tra chữ ký thực tế
  xác nhận điều đó; Tauri `.sig` không phải Authenticode.
- macOS public/free build hiện dùng ad-hoc signature và không được gọi là
  notarized trừ khi Developer ID/hardened runtime/stapler/spctl đều đạt.
