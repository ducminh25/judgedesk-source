# JudgeDesk v1.2.7 — Release checklist

Checklist này áp dụng cho đúng release commit `v1.2.7`. Windows MSI local,
CodeMagic updater signature và CodeMagic Apple Silicon artifacts phải cùng được
tạo từ commit này; không trộn artifact từ các commit trung gian.

## 1. Source gate trước khi đóng gói

Ghi lại commit:

```powershell
git status --short
git rev-parse HEAD
git rev-parse origin/main
```

Chỉ các thư mục evidence/local đã biết mới được phép untracked. Sau đó chạy:

```powershell
npm ci --no-audit --no-fund
npm run release:check-version
npm run lint
npm run test:server
npm run test:executor
npm run build:frontend
npm run build:server
cargo fmt --check --manifest-path src-tauri/Cargo.toml
cargo test --locked --manifest-path src-tauri/Cargo.toml
```

- [ ] Tất cả version là `1.2.7`.
- [ ] CI `windows-2022` và `macos-15` xanh trên exact release commit.
- [ ] Không có thay đổi tracked sau khi chạy gate.

## 2. Regression chức năng bắt buộc

### Reload selection — Windows

- [ ] Load thí sinh/problems, bỏ tick ít nhất một thí sinh và một problem.
- [ ] Bấm Reload: các mục cũ giữ nguyên trạng thái tick/untick.
- [ ] Thêm một thí sinh/problem mới rồi Reload: mục mới được tick mặc định.
- [ ] Xóa một mục khỏi filesystem rồi Reload: mục đó biến mất, không làm reset
  trạng thái các mục còn lại.

### Test discovery — Windows và macOS

Trong problem `Custom_Python`, cố ý để lại folder `__pycache__` cạnh `test01`.

- [ ] Màn hình Problem Configuration chỉ hiển thị `test01` và `1 total`.
- [ ] `__pycache__`, folder rỗng, input-only và output-only không xuất hiện.
- [ ] `Custom_AC_cpp / Custom_Python` đạt AC, 10 điểm.
- [ ] `Custom_HALF_cpp / Custom_Python` đạt PARTIAL, 5 điểm.

### Managed Python — macOS Apple Silicon

- [ ] Preferred Python source là Managed; System Status báo submission/checker
  ready và đúng version managed.
- [ ] Bài Python AC được chấm có điểm, không còn overall JE/0 hàng loạt.
- [ ] Đổi sang System/Custom Python: checker ready nhưng submission không ready.
- [ ] Gỡ Managed Python: submission Python fail closed, không chạy ngoài sandbox.
- [ ] Log CodeMagic có dòng managed Python compile-and-run smoke passed.

## 3. Known mismatch cần quyết định trước release

Stress fixture hiện kỳ vọng `Custom_JE_cpp / Custom_Python` với `result = 2`
phải là JE, 0 điểm. Parser hiện vẫn hiểu giá trị này là 2 điểm tuyệt đối và trả
PARTIAL, 2 điểm.

- [ ] Sửa parser để `result = x` chỉ nhận multiplier `[0,1]`; hoặc
- [ ] Chốt lại protocol/expected fixture rằng `result = 2` là điểm tuyệt đối.

Không ghi stress suite là `59/59` cho tới khi lựa chọn trên được triển khai và
test lại. Đây là vấn đề độc lập với Managed Python runtime và test discovery.

## 4. Windows MSI local

```powershell
npm run build:windows:local
```

- [ ] Có `JudgeDesk_1.2.7_x64_en-US.msi`.
- [ ] Cài Replace/upgrade từ `1.2.6`, dữ liệu và managed toolchains được giữ.
- [ ] Chạy lại regression ở mục 2 trong app đã cài.
- [ ] Ghi SHA-256 và trạng thái `Get-AuthenticodeSignature` của MSI.

`build:windows:local` không tạo updater `.sig` và không tự cung cấp
Authenticode publisher identity. Tauri updater signature xác thực update nhưng
không thay thế Authenticode/SmartScreen.

Để lấy updater signature:

1. Upload MSI đúng tên vào public prerelease `v1.2.7-staging`.
2. Chạy CodeMagic workflow `windows-updater-signing` trên exact release commit.
3. Tải MSI, `.msi.sig` và `SHA256SUMS-windows`; xác minh hash khớp bản đã test.

## 5. Apple Silicon trên CodeMagic

Chạy workflow `macos-arm64-release` trên exact release commit.

- [ ] Source/version/lint/server tests pass trước bước packaging.
- [ ] Native executor security suite, Apple Clang smoke và Managed Python smoke
  đều pass.
- [ ] Thu được `JudgeDesk_1.2.7_aarch64.dmg` (hoặc tên version tương đương),
  `JudgeDesk.app.tar.gz`, `.app.tar.gz.sig` và `SHA256SUMS-macos`.
- [ ] Cài DMG trên Mac M1/M2, Replace bản cũ và chạy lại mục 2.
- [ ] Nếu artifact không notarized, kiểm tra checksum trước khi dùng Gatekeeper
  **Open Anyway**; không mô tả release là notarized.

## 6. Ghép artifact và publish

Thư mục release cuối phải có tối thiểu:

```text
JudgeDesk_1.2.7_x64_en-US.msi
JudgeDesk_1.2.7_x64_en-US.msi.sig
JudgeDesk_1.2.7_aarch64.dmg
JudgeDesk.app.tar.gz
JudgeDesk.app.tar.gz.sig
SHA256SUMS-windows
SHA256SUMS-macos
latest.json
```

Tạo updater manifest sau khi đã đặt hai updater bundle và hai `.sig` vào cùng
`release-assets`:

```powershell
$env:PUBLIC_RELEASE_REPOSITORY='ducminh25/judgedesk'
$env:GITHUB_REF_NAME='v1.2.7'
node scripts/generate-updater-manifest.js release-assets
```

- [ ] `latest.json.version` là `1.2.7`, có `windows-x86_64` và
  `darwin-aarch64`, URL trỏ đúng tag `v1.2.7`.
- [ ] Tạo annotated tag `v1.2.7` trên exact release commit.
- [ ] Upload vào draft release, kiểm tra tải công khai mọi URL rồi mới publish.
- [ ] `latest.json` có mặt trước khi release trở thành `latest`.
- [ ] Sau khi xác nhận updater hoạt động, xóa prerelease `v1.2.7-staging`.
