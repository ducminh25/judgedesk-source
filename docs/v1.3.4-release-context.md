# JudgeDesk v1.3.4 release context

Ledger này fail-closed: chỉ đánh dấu `[x]` sau khi gate chạy trên exact release
candidate hoặc artefact cuối. Đọc code, test nhánh khác hay build cũ không thay
thế bằng chứng release.

## Phạm vi và định danh bất biến

- Version/tag: `1.3.4` / annotated private source tag `v1.3.4`.
- Nhánh chuẩn bị: `codex/v1.3.4-edition-updater`.
- Exact release SHA: `524c8aafa763112ecf356b20c9930176f4f3da8d`.
- Source/tag/CI: private `ducminh25/judgedesk-source`.
- Artefact và tài liệu public: `ducminh25/judgedesk`.
- Giữ identifier `com.themisv2.judge`, updater public/private-key lineage,
  Ed25519 toolchain key và MSI UpgradeCode
  `4ac645a9-f719-5210-85be-f03f49c33869`.
- Không dùng GitHub Actions làm build gate; Windows build local, macOS/Windows
  updater signature dùng CodeMagic như quy trình hiện hành.

## Quy tắc updater mới

- `latest.json` có đúng bốn target:
  `windows-x86_64-core`, `windows-x86_64-full`,
  `darwin-aarch64-core`, `darwin-aarch64-full`.
- Mỗi target nhúng đúng chữ ký payload, URL, edition, kích thước tải xuống và
  kích thước sau cài đặt.
- App kiểm tra cả Core và Full; hai target phải cùng version mới nhất. Thiếu một
  target, sai metadata hoặc lệch version là lỗi fail-closed, không tự chọn bản
  còn lại.
- Cập nhật cùng edition không hỏi xác nhận edition. Đổi Core ↔ Full phải giải
  thích ảnh hưởng toolchain và xác nhận trước download.
- Resource tải nhưng chưa cài được đóng khi hủy/recheck/thoát; plugin giữ payload
  đã tải trong bộ nhớ, không persist một installer trong Temp.
- v1.3.4 là manual cutover. Không tạo legacy target cho v1.3.0–v1.3.3 vì người
  dùng sẽ được hướng dẫn cài v1.3.4 thủ công.

Standalone `.sig` và `.metadata.json` chỉ là staging input, không public.
`SHA256SUMS` bao phủ đúng bảy public asset còn lại.
